# Game SFX

Selected sounds from Kenney RPG Audio and Impact Sounds (CC0). Original licenses are in Licenses/. Sources: https://kenney.nl/assets/rpg-audio and https://kenney.nl/assets/impact-sounds .

GameAudio loads named cues from Resources/SFX, varies pitch slightly, and uses a bounded eight-voice pool. Set Master Volume on the runtime Game SFX object to adjust all effects. Replace .ogg clips while retaining their .meta files to preserve assets.

Cues: swing (knifeSlice/knifeSlice2), dash (clothBelt), jump/air_jump (cloth1/cloth2), hurt (impactPunch_medium), player_death/slime_death (impactSoft_heavy), slime_hit (impactSoft_medium), land (footstep_concrete), and four variants each for snow, concrete and wood footsteps. No synthesized voice or music is included.
