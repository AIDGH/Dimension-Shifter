# Source of imported content

User-supplied local reference: `Game/HollowKnight-mini/assets`.

- `map`: Greenpath-room1.tmx, Greenpath-room2.tmx, BossRoom.tmx and referenced TSX definitions.
- `map_images`: only images referenced by these rooms.
- `player`: supplied Knight sprite sheets/effects; Idle, Run, Jump and Slash currently used.
- `enemies`: mossfly and husk_hornhead sheets.
- `Generated`: Unity geometry, materials, animation clips and controller generated by Tools/Hollow/HollowSetup.cs.
- Runtime gameplay is implemented in Unity C#; no Java source code is included.

Tiled transform reference: https://doc.mapeditor.org/en/stable/reference/global-tile-ids/ . UV lookup uses the inverse transform (horizontal/vertical, then diagonal swap); all four flags are cleared from the tile ID.
