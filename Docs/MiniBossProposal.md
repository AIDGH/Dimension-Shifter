# Original proposal: Rift Lantern Keeper

Historical design note. The user subsequently authorized implementation. The shipped demo uses the Rift Warden with the supplied False Knight artwork, pursuit, melee, ranged fans and alternating dimension vulnerability; see DemoRelease.md for the current design.

An original stone-armored guardian with a suspended blue lantern and a violet core. It protects a small, two-level chamber. This uses the game's existing Frost/Echo distinction rather than introducing another input.

1. In Frost, it warns clearly, then slams the ground. Baiting the slam into a marked seal staggers it for about four seconds.
2. Shift to Echo while it is staggered to expose the core. There is time for one or two normal strikes. The vulnerability window must accommodate the two-second Q cooldown, including reaction time.
3. In Echo, the lantern projects slow, readable arcs; jump or phase dash through gaps, then return to Frost to prepare the next opening. Solid platforms must never appear inside the player.
4. Below half health, combine the same learned patterns with a second telegraphed slam. Do not add an unexplained invulnerability rule or unavoidable damage during the shift cooldown.

Start with one arena, two attacks, three successful vulnerability cycles, an entrance checkpoint, and a clear victory reward. Keep the guardian's silhouette and animation simple enough for the contest deadline.

Inspiration: the official Hollow Knight description emphasizes interconnected exploration, distinct environments and creatures, and atmospheric music (https://www.hollowknight.com/). Hollow Knight's Geo/Soul systems inspire rewarding encounters, but this game's score/Resonance system is our own design, not a reproduction of a Hollow Knight XP system.
